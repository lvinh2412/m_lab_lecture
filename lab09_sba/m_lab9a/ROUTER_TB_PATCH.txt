*** NAM DIEU PHAI HIEU VE BON DONG NAY ***
=============================================================================

 (1) CHIEU CUA connect()

        port.connect(imp)      <- DUNG
        imp.connect(port)      <- SAI

     Luon goi tu phia PHAT (monitor). Nho bang chieu du lieu: du lieu
     chay tu monitor sang scoreboard, loi goi cung vay.


 (2) DUNG HANDLE, KHONG DUNG CHUOI

        yapp.tx_agent.monitor.item_collected_port
        ^^^^ ^^^^^^^^ ^^^^^^^ ^^^^^^^^^^^^^^^^^^^
         |      |        |            |
         |      |        |            +-- ten HANDLE cua port trong monitor
         |      |        +-- ten HANDLE cua monitor trong agent
         |      +-- ten HANDLE cua agent trong env
         +-- ten HANDLE cua env trong router_tb

     Day la truy cap thanh vien SystemVerilog binh thuong.

     *** SO SANH VOI config_db -- hai thu trong giong nhau ***

     +------------------+---------------------------+--------------------+
     |                  | config_db                 | TLM connect        |
     +------------------+---------------------------+--------------------+
     | dung gi          | CHUOI ten instance        | HANDLE (bien)      |
     | vi du            | "tb.yapp.tx_agent.sequencer" | yapp.tx_agent... |
     | go sai thi       | IM LANG, khong khop gi    | LOI BIEN DICH      |
     | co wildcard      | co (* va ?)               | khong              |
     +------------------+---------------------------+--------------------+

     => TLM connect AN TOAN HON NHIEU. Compiler kiem tra duoc tung ten.
        Day la mot trong it cho cua UVM ma go sai thi biet ngay.


 (3) CA BON MONITOR DUNG CUNG MOT TEN PORT

     yapp.tx_agent.monitor.item_collected_port
     chan0.rx_agent.monitor.item_collected_port
     chan1.rx_agent.monitor.item_collected_port
     chan2.rx_agent.monitor.item_collected_port
