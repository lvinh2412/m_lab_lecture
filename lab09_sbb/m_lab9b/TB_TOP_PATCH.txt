===============================================================================
[TB-2]  THEM dong import
===============================================================================

Them vao nhom import, SAU bon dong import UVC:

    // import the router module package
    import router_module_pkg::*;              <- THEM

    `include "router_mcsequencer.sv"
    `include "router_mcseqs_lib.sv"

bon dong import UVC phai dung truoc router_tb.sv (Lab 7).

*** SO SANH: `include VS import ***
=============================================================================

  +-------------------+-------------------------+----------------------+
  |                   | `include (Lab 9A)       | import (Lab 9B)      |
  +-------------------+-------------------------+----------------------+
  | lam gi            | DAN CHU vao vi tri do   | MO TAM NHIN toi ten  |
  | noi dung duoc copy| CO -- chu duoc nhan ban | KHONG -- chi tro toi |

  | can trong run.f   | khong                   | CO (file package)    |
  | pham vi class     | module tb_top           | package              |
  +-------------------+-------------------------+----------------------+
